Transformateur à vide

Le réseau impose au primaire une tension sinusoïdale, donc un champ sinusoïdal dans le noyau. Le courant qu’il faut pour cela se lit sur le cycle d’hystérésis : il n’est sinusoïdal que si le matériau est linéaire. La construction est celle de l’animation de Wikimedia Commons citée dans le cours.

Tension imposée, courant magnétisant

Le temps défile à partir du cycle, deux cents fois plus lentement qu’à 50 Hz : vers la gauche pour la tension et le champ, vers le bas pour le courant.
