Bobine avec cœur magnétique

Une tension sinusoïdale aux bornes de la bobine impose un champ sinusoïdal dans le cœur. Le courant qu’il faut pour cela se lit sur le cycle d’hystérésis : il n’est sinusoïdal que si le matériau est linéaire.

Tension imposée, courant dans la bobine

Le temps défile à partir du cycle, deux cents fois plus lentement qu’en réalité : vers la gauche pour la tension et le champ, vers le bas pour le courant.
